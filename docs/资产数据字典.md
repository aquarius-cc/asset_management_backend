# 资产数据字典

> 适用：资产管理系统后端（Python 3.12+ / Django 6.0 / DRF 3.15+ / MySQL 8.0）  
> 遵循：`AGENTS.md`（模型红线）、`ARCHITECTURE.md`（分层与模型约束）  
> 用途：数据库设计、模型开发、序列化器编写、查询优化的唯一依据。

---

## 1. 基础约定

| 约定项      | 强制要求                                                               |
| -------- | ------------------------------------------------------------------ |
| **字符编码** | 所有字符串字段默认 `utf8mb4`，支持 emoji                                       |
| **字段命名** | 下划线小写 `snake_case`（如 `asset_code`）；禁止中文或特殊字符                       |
| **主键**   | 统一 `id`，类型 `BIGINT AUTO_INCREMENT`（除非显式声明其他主键）                     |
| **时间字段** | `DATETIME`（UTC+8），创建/更新时间使用 `auto_now_add` / `auto_now`            |
| **软删除**  | 核心表必须包含 `is_deleted`，默认 `0`，查询需过滤 `is_deleted=0`                   |
| **版本控制** | 核心表包含 `version` 字段（`INT`，默认 1），用于乐观锁                               |
| **表名**   | 蛇形小写，资产模块前缀 `am_`（如 `am_asset`），设计阶段统一                             |
| **外键**   | 显式指明 `to_field`、`related_name`、`on_delete` 策略，`PROTECT`/`SET_NULL` |

## 4. 表关联关系概览

user (1) ─────< (N) asset_apply (申请人)  
user (1) ─────< (N) asset (领用人)  
role (1) ─────< (N) user (角色分配)  
asset_type (1) ─────< (N) asset (分类)  
supplier (1) ─────< (N) asset (供应商)  
asset (1) ─────< (0..1) asset_apply (新增申请对应一个资产)  
role ───< M:N >─── permission (通过 role_permission 中间表)

> **设计原则**：外键 `on_delete` 对核心数据使用 `PROTECT`，对非关键引用使用 `SET_NULL`，禁止级联物理删除。

## 5. 数据字典维护规则

- **新增字段**：必须同步本文档，注明字段用途、约束、示例，评审通过后执行迁移。
- **修改字段**：记录旧字段信息、修改原因，更新字典版本。
- **字段删除**：**禁止物理删除**。如需废弃，标记“已废弃”，保留字段但默认置空或设置 `is_deleted=1`。
- **版本管理**：按季度更新（如 `2024.Q2`），变更记录存入 `dict_version_log` 表。

## 6. Django 模型实现要点

以下为符合本字典的关键模型片段，所有模型务必继承 `core.models.BaseModel`（提供 `is_deleted`, `create_time`, `update_time` 等），此处示例已省略基类字段：

```
python

# apps/assetmanagement/models.py

from django.db import models

class AssetType(models.Model):
    type_name = models.CharField(max_length=50, unique=True, verbose_name="分类名称")
    parent_id = models.BigIntegerField(default=0, verbose_name="父分类ID")
    sort = models.IntegerField(default=0, verbose_name="排序权重")
    # 其他字段继承自 BaseModel

    class Meta:
        db_table = 'am_asset_type'

class Asset(models.Model):
    # 状态枚举
    class UseStatus(models.IntegerChoices):
        IN_STORE = 0, '入库'
        IN_USE = 1, '已领用'
        REPAIR = 2, '维修'
        SCRAPPED = 3, '报废'
        LOST = 4, '丢失'

    asset_code = models.CharField(max_length=32, unique=True, editable=False, verbose_name="资产编码")
    asset_name = models.CharField(max_length=100, verbose_name="资产名称")
    asset_type = models.ForeignKey(AssetType, on_delete=models.PROTECT, verbose_name="资产分类")
    spec = models.CharField(max_length=200, null=True, blank=True, verbose_name="规格型号")
    supplier = models.ForeignKey('Supplier', on_delete=models.SET_NULL, null=True, blank=True, verbose_name="供应商")
    purchase_price = models.DecimalField(max_digits=10, decimal_places=2, null=True, blank=True, verbose_name="采购价格")
    purchase_date = models.DateField(null=True, blank=True, verbose_name="采购日期")
    use_department = models.ForeignKey('Department', on_delete=models.SET_NULL, null=True, blank=True, verbose_name="使用部门")
    user = models.ForeignKey('User', on_delete=models.SET_NULL, null=True, blank=True, verbose_name="领用用户")
    use_status = models.IntegerField(default=UseStatus.IN_STORE, choices=UseStatus.choices, verbose_name="使用状态")
    warranty_period = models.IntegerField(null=True, blank=True, verbose_name="质保期（月）")
    address = models.CharField(max_length=200, null=True, blank=True, verbose_name="存放地址")
    sensitive_flag = models.BooleanField(default=False, verbose_name="敏感资产标识")
    remark = models.TextField(null=True, blank=True, verbose_name="备注")
    version = models.IntegerField(default=1, verbose_name="版本号")

    class Meta:
        db_table = 'am_asset'
        indexes = [
            models.Index(fields=['asset_code']),
            models.Index(fields=['use_status']),
            models.Index(fields=['user']),
        ]
```

🔴 **开发要求**：任何对模型字段的增删改必须对照本数据字典，并更新测试与迁移文件。所有资产核心模型默认管理器必须重写 `get_queryset` 过滤 `is_deleted=False`。
