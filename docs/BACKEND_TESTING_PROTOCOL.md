# 后端测试强制执行清单（BACKEND TESTING PROTOCOL）
> **⚠️ 红线警告**：本协议与根级 AGENTS.md §3.7 联动。执行 `python manage.py test` 前，必须逐项完成以下清单并输出证据，否则视为测试偷懒。

## 1. 测试文件拓扑（防遗漏）
- **一对一映射**：修改 `services/asset.py` → 必须对应 `tests/test_services/test_asset.py` 或 `tests/test_asset_service.py`。
- **命名强制**：测试类以 `Test<被测类名>` 开头，测试方法必须遵循：
  `test_<方法名>_<预期结果>_when_<触发条件>`
  *示例：`test_calculate_discount_returns_zero_when_price_is_negative`*

## 2. 边界值字典（防偏差——必须直接引用以下硬编码值）
AI 在编写测试数据时，必须从下表中**至少选取 80% 的异常值**，禁止全部使用常规值（如 `price=100`）：

| 分类 | 强制使用的异常值（直接复制到代码中） |
| :--- | :--- |
| **数值** | `-1`, `0`, `10**18` (超大), `0.1 + 0.2` (浮点精度), `float('inf')`, `None` |
| **字符串** | `""` (空), `"a"*1001` (超长), `"'; DROP TABLE--"` (注入), `"😊😊😊"` (特殊字符) |
| **关系ID** | `0`, `999999` (不存在), `uuid.uuid4()` (随机无效UUID) |
| **日期** | `datetime(1970,1,1)`, `datetime(9999,12,31)`, `datetime(2024,2,29)` (闰年) |
| **权限** | `None` (未认证), `{"token": "expired"}` (过期/无效), 其他租户的 `tenant_id` |

## 3. 原子化测试法则（Anti-Batching —— 防自我放过）
- **禁止“万能测试”**：一个测试方法**只能覆盖一个边界类别**（例如负数）或一个异常场景。
- **强制拆分**：针对同一个函数，如果需测试“负数”、“零”、“超大数”，必须拆分为 **3 个独立测试方法**。
  - ❌ *错误示范*：`def test_numeric_boundaries(self):`（里面塞了3个断言） → **视为违规，需重构**。
  - ✅ *正确示范*：`def test_negative(self):` / `def test_zero(self):` / `def test_huge(self):`
- **断言锁死**：每个测试用例必须至少包含 **1 个数据库状态断言**（如 `assert count == 1`）或 **1 个精准异常码断言**（如 `assert response.json()['code'] == 40001`）。**严禁**仅使用 `assert True` 或 `assert response.status_code == 200` 作为唯一断言。

## 4. Mock 敬畏协议（防自我放过）
- **必须模拟失败**：若代码调用了外部 API（如第三方支付），除了模拟成功返回外，**必须单独开一个测试用例**模拟 `TimeoutError` 或 `HTTP 500`，并断言代码返回了兜底错误信息，而非直接崩溃。
- **调试验证**：在 Mock 外部函数后，必须断言该 Mock 被调用了预期次数（`assert_called_once_with(...)`），防止代码因逻辑错误根本没走到外部调用。

## 5. 事务回滚强制验证（涉及写操作时）
若被测函数带有 `@transaction.atomic`，测试必须包含：
1. 正常用例（验证数据已提交）。
2. **异常用例**：故意在函数中途抛出异常，随后断言数据库中的记录数/字段值与操作前**完全一致**（证明事务回滚生效）。

## 6. 执行前自检清单（强制输出）
在运行测试命令**之前**，AI 必须输出以下清单，否则父引擎按缺失证据处理：
```text
[测试预检] 
- 覆盖的边界类别（至少勾选3类）：数值[ ] 字符串[ ] 关系[ ] 日期[ ] 权限[ ]
- 计划编写的测试用例数：<X>（正向：<X>，异常：<X>）
- 涉及的 Mock 场景：成功[1个] / 失败[模拟超时/500]（如适用）
- 数据库事务回滚验证：是 / 否（如适用）
